Python Runner

Privacy Policy

Last updated: September 16, 2026

Python Runner is a browser extension that runs Python code inside your browser. This policy describes exactly what it does with data — which is nothing.

What the extension collects

Nothing. The extension does not collect, store on any server, sell or share any personal data, browsing history, code or usage statistics. It has no accounts, no tracking and no third-party analytics inside the extension.

What stays in your browser

Your draft, saved snippets and settings are kept in your browser's extension storage (chrome.storage.local for code, chrome.storage.sync for settings). Settings may sync between your own Chrome profiles through Chrome Sync, which is controlled by your Google account, not by us. Everything is deleted automatically when you remove the extension.

Code execution

Python runs inside the extension, on your device, using CPython compiled to WebAssembly (Pyodide). Scripts cannot reach the network or your files. The extension itself makes no network requests at all.

Pages the extension opens

  • After installation it opens a one-time welcome page, and after removal your browser opens a feedback page — both are ordinary web pages hosted on GitHub Pages. They may use standard, anonymous web analytics.
  • Feedback you choose to submit on the removal page (a reason and an optional comment) is sent to the developer via Google Forms. Submitting it is entirely optional and it contains only what you type — no identifiers are attached by the page.

Permissions, explained

  • storage — to keep your snippets, draft and settings locally.
  • contextMenus — to add “Run selected Python” to the right-click menu.
  • activeTab and scripting — to read the text you selected on the current page, only at the moment you click that menu item. The extension does not run on any page otherwise and never modifies pages.
